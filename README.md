Fashion Store - E-Commerce Platform
A dynamic, database-driven web application that simulates a modern online apparel shopping experience. Built with a robust Java backend and a structured relational database, this project demonstrates end-to-end e-commerce functionality, from user cart operations to variant inventory management.

**Key Features**
**User Authentication:** Secure login and registration with persistent session management.
**Product & Category Management:** Browse apparel collections filtered by categories and search items dynamically.
**Cart Operations:** Complete cart management including item additions, quantity adjustments, and dynamic total price updates.
**Order Processing & History:** Streamlined checkout workflow converting active cart items into persistent user order records.

**Tech Stack**
**Frontend:** HTML5, CSS3, JSP (JavaServer Pages), JavaScript
**Backend:** Java Servlets, JDBC, Spring Boot / Java Enterprise Architecture
**Database:** MySQL
**Server:** Apache Tomcat

**Local Setup Instructions**
**Clone this repository:**
   ```bash
   git clone [https://github.com/samyuktha26-hub/ecommerce-backend-platform.git](https://github.com/samyuktha26-hub/ecommerce-backend-platform.git)

    Setup Database: Run the provided SQL setup script (database_setup.sql) in MySQL Workbench to create the schema and seed data.

    Configure Database Connection: Update the database configuration file with your local MySQL credentials (username and password).

    Deploy Application: Deploy the project on an Apache Tomcat Server via Eclipse or IntelliJ IDEA.

    Access App: Open http://localhost:8080/ecommerce-backend-platform in your web browser.
